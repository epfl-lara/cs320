# EPFL CS320 - CLP - Computer Language Processing

Links: [Moodle](https://moodle.epfl.ch/course/view.php?id=4241) and [Course Description](https://edu.epfl.ch/coursebook/en/computer-language-processing-CS-320)

This project will contain substantial changes compared to previos years edition, includnig forms of examination (primarily in class), content covered, as well as languages and tools used. In fact, CLP might as well stand for *Computer Languages and Proofs*. Computer languages are formal languages and they are used in interpreters, compilers, and proof assistants such as [Lean](https://lean-lang.org/) that check if a mathematical proof is correct.
